# KeyPrice

Marketing site for KeyPrice, a group-buying service for brand-new cars in India.

This repository is deployed as a free Render static site: https://keyprice-media.onrender.com

The scroll hero scrubs pre-extracted WebP frame sequences (`public/frames/`) on a canvas — about 60–90 frames per clip at 1280×720, lazy-loaded. Source MP4s remain in `public/` but are not used for the hero. The live Grok Bot canvas is a separate page and is not updated from here.
